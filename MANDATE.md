# Mandate — hello-ai

## Why this exists
Hello Tractor runs on people at very different points on the AI-fluency curve —
from staff who only ever type a question into a chat box, to builders who
assemble Projects/artifacts and connect data sources, to engineers running
Claude Code against real codebases. This repo is the material for the Nairobi
all-hands session that meets each of those groups where they are, and it is
also the seed of a reusable practice (**ATLAS**) so any HT team can run an
AI-assisted project that stays on-mandate over time instead of drifting.

## Audience
All-hands, Hello Tractor, Nairobi. Assume a full spread: non-technical
operations/business staff through software engineers. No prior AI tooling
experience assumed; nothing dumbed down for the engineers either — the tiers
in `content/` are additive, not remedial.

## What "done" looks like
- A live session (reveal.js deck, published via GitHub Pages at
  `helloai.atarigo.net`) that walks: why this matters now (adoption shift)
  → everyday chat use → builder tools (artifacts/connectors) → engineering
  use (Claude Code) → privacy rules that apply at every tier → the
  enterprise AI charter → project scoping and agent freedom → staying on
  track (drift/retros) → the ATLAS framework itself.
- A `templates/atlas/` folder any HT team can copy into their own repo to
  start an AI-assisted project with a Mandate, Contract, live State, and
  (optionally) a Sprint/Retro cadence from day one.
- Attendees leave able to answer, for their own work: *which tier am I
  operating at, and what's safe for me to paste into that tool?*

## Non-goals
- Not a general "AI is transformative" hype talk — every slide should be
  something a specific HT role can act on Monday morning.
- Not a pitch for one vendor — Claude is the primary example (it's what's
  available), Gemini/others are named where relevant, but the framework
  (ATLAS) is tool-agnostic.
- Not a substitute for HT's actual data-handling/security policy — this repo
  points to that policy, it doesn't replace it.
