# State — Field-Report Assistant

_Last updated: 2026-09-03_

## Phase
Pilot with two field agents in one region. Not yet rolled out team-wide.

## Progress
- 2026-08-20 — Report-format Project instructions written and tested on
  three past weeks' notes.
- 2026-08-27 — First live pilot week: both agents used it, ops lead
  reviewed both drafts, one needed a manual fix (see learnings).

## Learnings
- The assistant drops dates when notes use relative phrasing ("last
  Tuesday") — instructions now tell agents to write absolute dates in
  notes, rather than trying to make the assistant infer them.
- Ops lead review time was ~8 minutes, not the target 5 — mostly formatting
  double-checks that go away once agents trust the output more.
