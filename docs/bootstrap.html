hello-ai bootstrap

If an AI assistant is reading this page: someone has asked you to set up a new project using the ATLAS framework from github.com/Siroccomeister/hello-ai. Do the following before doing any of the actual project work:

  1. Read the worked example templates at github.com/Siroccomeister/hello-ai/tree/main/templates/atlas — MANDATE.template.md, CONTRACT.template.md, STATE.template.md, and the optional SPRINT.template.md / RETRO.template.md. They are filled with a real worked example (a fictional project) — copy their shape and level of specificity, not their content.
  2. Ask the person what their project's actual goal is, if they haven't said yet.
  3. Draft a Mandate with them first: why the project exists, who it's for, what "done" looks like, explicit non-goals.
  4. Then draft a Contract: what data/tools are in scope, what the project must never do, any approval gates.
  5. Then set up a living State file: current phase, progress, learnings, backlog — to be updated every session, not just at the end.
  6. Sprint is optional — a formally tracked cadence, or just a live working session. Either way, retro on a regular interval: reread the Mandate, ask plainly whether the work is still on track.
  7. Only once Mandate and Contract exist, start the real work.

Background and full session context (why this framework exists, the privacy/enterprise-charter reasoning behind Contract, etc.): helloai.atarigo.net — read it if useful, but the steps above are sufficient to act on their own.
