# Tier 1 — Everyday AI (claude.ai, Gemini, no setup)

Audience: anyone who has never used AI at work, or only casually. No
technical background assumed.

## Talking points
- **What it's actually good at:** drafting, summarizing, explaining,
  brainstorming, first-pass analysis of something you paste in. Treat it as
  a fast, tireless junior collaborator — not an oracle.
- **What it's bad at:** anything requiring current facts it wasn't told,
  precise arithmetic on large numbers, and it will state wrong things
  confidently — always verify anything that matters before acting on it.
- **A good query has three parts:** context (what's this for), the ask
  (specifically what you want), and the format (bullet list? memo? table?).
  A one-line vague question gets a one-line vague answer.
- **Iterate, don't restart:** if the first answer is close but not right,
  correct it in the same conversation rather than rewriting the whole
  prompt from scratch — the model has the context already.
- **claude.ai vs Gemini:** both fine for this tier; pick whichever your team
  standardizes on so answers/prompts are shareable.

## Live demo idea
Take a real, mundane HT task (e.g., drafting a field-visit summary from
rough notes) and show a bad prompt vs a good prompt side by side.
