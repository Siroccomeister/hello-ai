# The quickstart prompt

The close of the session, and the actual point of the whole talk: everyone
leaves with one thing they can paste into an AI chat *today*, for whatever
they're working on — not just a version of this presentation.

## What to say on stage
"You don't need to remember any of the ATLAS detail. You need one prompt."

## The prompt (say it, show it, let people photograph the slide)

> I want to start a new project for **[describe your goal — anything, not
> a presentation]**. Set it up using the ATLAS framework described at
> https://helloai.atarigo.net — Mandate, then Contract, then a living
> State file, with Sprints optional. Use the worked examples at
> https://github.com/Siroccomeister/hello-ai/tree/main/templates/atlas as
> a model for the shape and level of detail — not the content. Start by
> drafting the Mandate with me, then the Contract, before we do any actual
> work.

## Why this specific wording works
- **Names the framework and gives a real, working link** — the assistant
  can fetch both the session content and the templates rather than
  guessing at what "ATLAS" means from the word alone.
- **Orders the steps explicitly** (Mandate → Contract → State) so the
  assistant doesn't jump straight to doing the task before the guardrails
  exist — the single most common failure mode this whole framework is
  built to prevent.
- **"Not a presentation"** is the point: the goal is deliberately left
  open. This works for a field-ops workflow, a personal project, a
  software feature, a marketing campaign — anything.

## What "done" looks like for this closing moment
Someone in the room opens their phone or laptop, pastes a version of this
prompt with their own real goal filled in, and has a Mandate drafted before
they leave the room.
